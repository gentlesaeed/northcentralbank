ABOUT NORTH CENTRAL

A banking simulation, built to explore.

Designed for learning and demonstration — not for real financial services.

N

North Central Bank simulation

This Django application is an educational banking simulation. It provides simulated account management, internal transfers, loan and account-tier request workflows, a transaction ledger, reports, and account settings.

ⓘ

Important: No real funds are held or transferred. Loan requests are not credit-assessed or funded. Two-factor settings are preferences only and do not send verification codes. Do not enter real financial or sensitive personal information.

For local development

Use a local SQLite database and the Django development server. Before any internet deployment, set a private DJANGO_SECRET_KEY, disable debug mode, configure allowed hosts, and complete a security review. This simulation is not intended for production banking.
